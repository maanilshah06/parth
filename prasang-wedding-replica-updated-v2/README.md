# Parth Weds Rutika — Prasang Planners

Responsive Next.js wedding invitation site. The main wedding date is set to **11 February 2026**.

## Included
- Large editorial hero with enlarged couple names
- Themed Mehendi, Haldi, Wedding Ceremony and Reception cards
- Live countdown, story, RSVP form and guest information section inspired by the supplied Framer reference
- WhatsApp contact link to Prasang Planners
- Prasang Planners logo and contact details in the footer
- Responsive mobile layout and reduced-motion support

## Run locally
Requires Node.js 20.9+.

```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Deploy
Push this folder to GitHub and import it at https://vercel.com/new. No environment variables are required.

## Before publishing
Confirm the date, venue, timings, guest information and RSVP process. The requested date, 11 February 2026, is in the past as of October 2026. The RSVP form currently opens an email app; responses are not saved in a database. Replace the illustrative hero stock photo with approved wedding photography if desired.
